I put language models where the work already happens — a chat that is already
open, a page you are already on, a terminal you are already in. Rarely a new
window. Backend on Java and Spring, frontend on React and TypeScript, Python
wherever it is simply faster to write.

Quality is part of the job rather than a stage after it: I write the cases,
cover the flows end-to-end, and go through the API before there is any UI to
click on.
